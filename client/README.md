# ✈️ Google Flights Clone (React + Vite + TailwindCSS)

A responsive flight search interface inspired by Google Flights, powered by the [Sky Scrapper API](https://rapidapi.com/apiheya/api/sky-scrapper).

## 🚀 Features

- Responsive flight search form (From, To, Date)
- Modern UI with TailwindCSS
- Powered by React (Vite)
- TODO: Flight results from RapidAPI (Sky Scrapper)
